# Dozator-automat-de-pastile-cu-carusel-
Dozator automat de medicamente: un servomotor rotește un carusel și eliberează doza la ora programată, un buzzer anunță ora, iar un senzor de proximitate confirmă că doza a fost luată (altfel se înregistrează ca ratată). Orarul și istoricul se păstrează în EEPROM și se gestionează de pe PC prin USART.
